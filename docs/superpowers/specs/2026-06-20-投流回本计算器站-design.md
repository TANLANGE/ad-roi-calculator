# 投流回本计算器站 - 设计文档

## 产品定位

**产品名称**：投流回本计算器

**一句话定位**：帮投流用户快速测算"花多少钱、赚多少钱、多久回本"的免费工具站

**目标用户**：
- 做抖音/小红书/百度/腾讯广告投放的中小企业主
- 个人创业者、副业人群
- 电商卖家（淘宝、拼多多、独立站）
- 代运营公司（可作为给客户的免费工具）

---

## 核心功能（第一版 MVP）

| 工具 | 核心公式 | 用户输入 | 输出结果 |
|---|---|---|---|
| `投流ROI计算器` | ROI = (收入 - 成本) / 成本 × 100% | 广告花费、订单数、客单价、毛利率 | ROI百分比、净利润、单客成本 |
| `回本周期计算器` | 回本月数 = 总投入 / 月净利润 | 初始投入、月广告费、月订单、客单价 | 回本月数、累计利润曲线 |
| `毛利计算器` | 毛利 = 售价 × 数量 - 成本 × 数量 - 广告费 | 售价、成本、数量、广告费 | 毛利率、净利润、单件利润 |


### 页面逻辑
- 每个工具页 = 独立落地页，可单独被搜索引擎收录
- 工具页顶部直接展示计算器，不需要跳转
- 计算结果出来后，展示"保存报告 → 填写邮箱"的留资入口
- 每个工具页底部放"相关文章"链接，互导流量
- 文章页底部放工具入口，形成 SEO 闭环

## 技术方案

| 维度 | 方案 | 理由 |
|---|---|---|
| 前端框架 | `Next.js`（静态导出） | 静态页面SEO最优，部署简单 |
| UI框架 | `Tailwind CSS` | 快速出样式，适配移动端 |
| 图表 | `Chart.js` 或 `ECharts` | 回本周期曲线、利润可视化 |
| 表单/留资 | 前端直接调第三方 | 用 `Formspree` 或 `EmailJS`，零后端 |
| 部署 | `Vercel`（免费） | 自动HTTPS、CDN、无需服务器 |
| 域名 | 待购买 | 所有工具和文章放同域名下 |
| 服务器 | 待购买 | 先本地开发，部署时再决定 |

### 开发顺序
1. 首页 + 投流ROI计算器（核心MVP）
2. 回本周期计算器
3. 毛利计算器
4. 3-5篇SEO文章
5. 留资表单接入

## 变现路径

| 阶段 | 变现方式 | 触发条件 |
|---|---|---|
| 初期 | Google AdSense 广告 | 日UV>100时接入 |
| 初期 | 联盟营销（推广投放工具/课程） | 文章中嵌入推荐链接 |
| 中期 | 会员订阅（高级报告导出/更多工具） | 有稳定用户群后 |
| 中期 | 咨询服务入口（投放诊断/代运营） | 放在留资转化后端 |
| 长期 | 卖模板包（投流计划表、利润模型Excel） | 积累信任后 |

## 设计约束

- 移动优先，适配手机和平板
- 工具页面首屏即计算器，不需要滚动
- 计算结果即时展示（无页面跳转）
- 颜色风格：专业、简洁、信任感（蓝色/绿色系）
- 中文界面，面向国内市场
